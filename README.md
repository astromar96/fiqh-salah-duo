# فقه الصلاة — Duolingo-style POC

تطبيق ويب لتعلّم فقه الصلاة بأسلوب دويلينجو. بدون أي build أو تبعيات.

## التشغيل

```bash
cd ~/fiqh-salah-duo
python3 -m http.server 8787
# افتح http://localhost:8787
```

(يعمل أيضًا بفتح `index.html` مباشرة.)

## الملفات

| الملف | الدور |
|---|---|
| `content.js` | **كل المنهج**. عدّله وحده لتغيير الدروس — لا تلمس `app.js` |
| `app.js` | محرّك اللعبة: المسار، الأسئلة، التصحيح، القلوب، السلسلة، الحفظ |
| `styles.css` | التصميم (موبايل أولًا، RTL) |
| `index.html` | الهيكل |

## ما هو مُنفَّذ

- مسار دروس متعرّج: ٦ وحدات، ١٧ درسًا، ~٩٨ عنصرًا
- ٥ أنواع أسئلة + بطاقات تعليم: `mcq` · `tf` · `order` · `match` · `fill` · `info`
- قلوب (٥، تمتلئ بعد ٢٠ دقيقة)، نقاط XP، سلسلة أيام 🔥
- السؤال الخاطئ يعود لآخر الطابور حتى يُجاب صحيحًا
- شرح بعد كل إجابة
- الحفظ في `localStorage` (مفتاح `fiqhSalahDuo.v1`)

## إضافة سؤال

أضف عنصرًا في `items` لأي درس في `content.js`:

```js
{ t:'mcq',   q:'السؤال', o:['أ','ب','ج'], a:1, e:'الشرح' }
{ t:'tf',    q:'العبارة', a:true, e:'الشرح' }
{ t:'order', q:'رتّب', items:['أولًا','ثانيًا'], e:'الشرح' }
{ t:'match', q:'وصّل', pairs:[['أ','١'],['ب','٢']], e:'الشرح' }
{ t:'fill',  q:'جملة فيها ____ فراغ', bank:['أ','ب'], a:'أ', e:'الشرح' }
{ t:'info',  h:'العنوان', b:'نص تعليمي' }
```

## ملاحظة فقهية

التقسيم (أركان/واجبات/سنن، وعدد الشروط) على **المذهب الحنبلي**، وهو مكتوب في `CONTENT.meta.note`.
المحتوى للتدريب ويحتاج مراجعة طالب علم قبل أي نشر.

## لاحقًا (غير منفّذ)

- مراجعة ذكية (spaced repetition) للأسئلة المخطئة عبر الدروس
- وضع "اختبار سريع" لفتح وحدة كاملة
- صوت/نطق، ولوحة متصدرين
